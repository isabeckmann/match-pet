# Match Pet

App para animais encontrarem um lar e tutores encontrarem companhia.

## Como rodar

```bash
npm install
cp .env.example .env   # preencher as chaves
npm run dev
```

## Scripts

- `npm run dev` - servidor de desenvolvimento
- `npm run build` - build de produção
- `npm run lint` - ESLint (inclui regras de acessibilidade)

## Stack

React, TypeScript, Vite, Tailwind CSS, React Router, React Hook Form, Zod, Axios, Firebase.
